# Seal Battery

แอพ Android ดูสถานะแบตเตอรี่ BYD Seal ผ่านอะแดปเตอร์ OBD2 Bluetooth (ออกแบบสำหรับ Vgate iCar Pro 2S)

## 1. สร้างไฟล์ APK ด้วย GitHub (ทำบนคอมพิวเตอร์ ไม่ต้องลงโปรแกรม)

1. แตกไฟล์ SealBattery.zip
2. สมัคร/เข้าสู่ระบบที่ https://github.com
3. กด **+** มุมขวาบน > **New repository** ตั้งชื่อ `SealBattery` เลือก **Private** แล้วกด **Create repository**
4. กดลิงก์ **uploading an existing file**
5. เปิดโฟลเดอร์ `SealBattery` เลือก **ทุกอย่างข้างใน** (รวมโฟลเดอร์ `.github`) ลากไปวางในหน้าเว็บ แล้วกด **Commit changes**
6. เปิดแท็บ **Actions** รอรายการ **Build APK** ขึ้นเครื่องหมายถูกสีเขียว (ประมาณหลายนาที)
7. กดเข้าไปที่รายการนั้น เลื่อนลงหัวข้อ **Artifacts** ดาวน์โหลด `SealBattery-apk` แล้วแตกไฟล์ จะได้ `app-debug.apk`

ถ้าในแท็บ Actions ไม่มีรายการ แปลว่าโฟลเดอร์ `.github` ไม่ได้ถูกอัปโหลด:
กด **Add file > Create new file** พิมพ์ชื่อ `.github/workflows/build.yml`
คัดลอกเนื้อหาจากไฟล์ build.yml ในเครื่องไปวาง แล้วกด **Commit changes**

ถ้าขึ้นกากบาทสีแดง: กดเข้าไป คัดลอกข้อความผิดพลาดส่งมาให้ช่วยแก้

(ทางเลือก: เปิดโฟลเดอร์ด้วย Android Studio แล้วเลือก Build > Build APK)

## 2. ติดตั้ง

- มือถือ: ส่ง `app-debug.apk` เข้ามือถือ กดเปิด แล้วอนุญาตการติดตั้งจากแหล่งที่ไม่รู้จัก
- จอรถ: ใส่แฟลชไดรฟ์แล้วติดตั้งแบบเดียวกับแอพอื่น

แนะนำให้ลองบนมือถือก่อน เพราะจอรถบางเครื่องอาจต่ออุปกรณ์ Bluetooth แบบนี้ไม่ได้

## 3. ใช้งาน

1. เปิดแอพ กด **เชื่อมต่อ > โหมดทดลอง** เพื่อดูหน้าจอก่อน แล้วกด **หยุด**
2. เสียบ iCar Pro 2S ที่ช่อง OBD2 (ใต้คอนโซลฝั่งคนขับ) และเปิดระบบรถ
3. ปิดแอพ OBD อื่น (เช่น Car Scanner) เพราะอะแดปเตอร์ต่อได้ทีละแอพ
4. เลือกวิธีต่ออย่างใดอย่างหนึ่ง
   - แบบจับคู่: ตั้งค่า Android > Bluetooth > จับคู่ชื่อประมาณ `Android-Vlink` (ถ้าถามรหัส ลอง 1234 หรือ 0000)
   - แบบ BLE: ไม่ต้องจับคู่ (ชื่อประมาณ `IOS-Vlink`) Android 11 ลงไปต้องเปิดตำแหน่ง (Location) ด้วย
5. ในแอพ กด **เชื่อมต่อ** แล้วเลือกอุปกรณ์

## อุณหภูมิน้ำหล่อเย็นและมอเตอร์

| ค่า | สถานะ |
|---|---|
| มอเตอร์หน้า | ตั้งรหัสไว้แล้ว (กล่อง 7E3 รหัส 000F) จากรายงานของผู้ใช้ Seal รายเดียว ยังไม่ยืนยัน |
| มอเตอร์หลัง | ยังไม่พบรหัส ต้องค้นหา |
| น้ำหล่อเย็น | ยังไม่พบรหัส ต้องค้นหา |

### วิธีค้นหา (ทำตอนจอดรถเท่านั้น)

1. จอดรถให้เย็น (เช่น จอดข้ามคืน) เปิดระบบรถ แล้วเชื่อมต่อในแอพ
2. กด **ตั้งค่า > เซนเซอร์ > เริ่มค้นหาเซนเซอร์** รอจนรายการผลขึ้น
3. กด **หยุด** ขับรถสัก 15-20 นาที แล้วจอด
4. เชื่อมต่อและค้นหาอีกครั้ง ค่าที่เปลี่ยนจะอยู่บนสุด
5. แตะค่าที่น่าจะใช่ แล้วเลือกว่าเป็นน้ำหล่อเย็นหรือมอเตอร์

ข้อสังเกต: ค่าที่เปลี่ยนไม่จำเป็นต้องเป็นอุณหภูมิ (แอพแปลงทุกค่าเป็น "ค่าดิบ - 40")
อุณหภูมิจริงควรใกล้อุณหภูมิอากาศตอนรถเย็น และค่อย ๆ เปลี่ยนหลังขับ
การค้นหาอ่านเฉพาะกล่อง 7E0-7E7 รหัส 0001-0060 จึงอาจไม่เจอ ถ้าไม่เจอให้ส่งบันทึกมา

## SOH

- ค่าเริ่มต้นเป็น **SOH โดยประมาณ** = ความจุที่ BMS รายงาน (7E7 รหัส 1FFC ไบต์ที่ 3-4) / ความจุอ้างอิง
- ความจุอ้างอิง: อ่านจากรหัส 1FFE ถ้าอ่านไม่ได้ใช้ 150 Ah (คำนวณจากแพ็ก 82.56 kWh) หรือกำหนดเองที่ **ตั้งค่า**
- รหัสสองตัวนี้อ้างอิงจาก BYD Atto 3 / e2 **ยังไม่ยืนยันกับ Seal** และอาจไม่ตรงกับค่าที่ศูนย์บริการวัด
- แบต LFP ควรชาร์จเต็ม 100% เป็นระยะตามคู่มือรถ เพื่อให้ BMS ประเมินค่าได้ดีขึ้น
- ถ้าขึ้น "รอค่าความจุจากรถ" ตลอด แปลว่ารถไม่ส่งค่านี้
- ทางเลือก: มีรายงานจาก BYD e2 ว่ารหัส 0029 *อาจ* เป็น SOH (ไม่ยืนยัน) ถ้าผลค้นหาเซนเซอร์มี `7E7 รหัส 0029`
  และค่าดิบสมเหตุสมผล (เช่น 90-100) เลือกใช้เป็น SOH ได้ ยกเลิกด้วย **คืนรหัสเซนเซอร์เป็นค่าเริ่มต้น**

## การอัปเดตจากเวอร์ชันก่อน

อัปโหลดไฟล์ทั้งหมดทับใน repository เดิม (Add file > Upload files) แล้ว Commit
รอ Actions สร้าง APK ใหม่ จากนั้นติดตั้งทับแอพเดิมได้

## ข้อควรระวัง

- **กด "หยุด" และถอดอะแดปเตอร์ก่อนล็อกรถ** มีผู้ใช้ BYD Seal รายงานว่าการอ่านข้อมูล OBD ตอนล็อกรถทำให้สัญญาณกันขโมยดัง (บางคนหายหลังอัปเดตซอฟต์แวร์รถ)
- ห้ามกดใช้งานแอพขณะขับรถ
- แอพส่งเฉพาะคำสั่งอ่านข้อมูล (UDS 0x22) ไม่เขียนหรือสั่งงานรถ

## ข้อจำกัด

- รหัสข้อมูลมาจากชุมชนผู้ใช้ ไม่ใช่เอกสารของ BYD และยังไม่ได้ทดสอบกับรถของคุณ ควรเทียบ % กับหน้าปัด
- ยังไม่มี SOH และแรงดันรายเซลล์ทุกเซลล์ (ยังไม่พบรหัสที่ยืนยันได้)
- พลังงานคงเหลือ = SOC x ความจุ (ค่าเริ่มต้น 82.5 kWh) และระยะทาง = พลังงาน / อัตราสิ้นเปลือง (18 kWh/100 กม.) แก้ได้ที่ปุ่ม **ตั้งค่า**
- ถ้าตอนชาร์จแสดง "จ่ายไฟออก" ให้ติ๊ก **กลับเครื่องหมายกระแส**

## ถ้าอ่านค่าไม่ได้

รหัสทั้งหมดอยู่ในไฟล์ `app/src/main/java/com/sealbattery/obd/Metric.java`
